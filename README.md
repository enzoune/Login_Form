# 🔐 Modern Login Interface (Portal de Autenticação)

> Uma interface de login elegante, focada em usabilidade e validação de dados, desenvolvida como parte do meu portfólio de estudos em Programação Full-Stack.

## 📖 Sobre o Projeto

Este projeto demonstra a criação de um componente de autenticação robusto. O objetivo foi aplicar conceitos de **design centrado no usuário**, garantindo que o fluxo de entrada de credenciais seja claro, rápido e visualmente profissional.

A interface inclui campos para e-mail/telefone, senha, recuperação de credenciais e um link de conversão para novos cadastros, cobrindo os requisitos essenciais de um módulo de autenticação real.

## ✨ Destaques e Diferenciais Técnicos

* **Validação Nativa de Formulário:** Uso do atributo `required` para garantir que os dados sejam preenchidos antes da submissão, reduzindo erros de entrada no lado do cliente.
* **Integração de Iconografia (Boxicons):** Uso de ícones vetoriais (`bx-user`, `bx-lock`) que servem como pistas visuais (affordances), melhorando a escaneabilidade da página.
* **Hierarquia Visual Clara:** Estruturação através de classes como `.wrapper` e `.title` para organizar o conteúdo de forma lógica e modular.
* **UX de Recuperação e Conversão:** Inclusão estratégica de links para "Esqueceu a senha?" e cadastro de novos membros, focando na retenção do usuário.
* **Organização de Código:** Separação estrita entre a estrutura de marcação (`index.html`) e a identidade visual (`css/style.css`), seguindo padrões de engenharia de software.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Marcação estrutural e lógica de formulário.
* **CSS3:** Gerenciamento de layout, tipografia e design responsivo.
* **Boxicons:** Biblioteca de ícones para suporte visual e interface.
